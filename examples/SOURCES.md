# Example Sources

The images in `test-matrix/` are finished outputs from the formal Photo Paper Folio Skill test.

The source photographs used for these evaluations were supplied by the project author for testing and span landscape, still life, people, architecture, vehicles, harbor scenes, animals, everyday objects, and city scenes.

The public examples are intended to demonstrate Skill behavior across varied photographic subjects. They are not runtime reference images, hidden style-conditioning assets, or training fixtures.
